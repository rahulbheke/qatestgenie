# Test Case Genie

Create an interactive web app where users input a feature and it generates structured test cases with positive, negative, and edge scenarios. Add clean UI, buttons, and dynamic output.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://testcasegen.lovable.app

## Build with Lovable
